Алгоритмизация - Задачки

Базовые задачи

Изучай алгоритмы шаг за шагом. Примеры, объяснения и интерактивная песочница для рисования.

Задача 1: Сумма чисел цикл

Найти сумму всех целых чисел от 1 до N.

let sum = 0;
for (let i = 1; i <= n; i++) {
sum += i;
}
console.log(sum);

Объяснение: Используем цикл for, накапливая сумму в переменной sum. Сложность O(n).

Задача 2: Факториал рекурсия / цикл

Вычислить факториал числа N (N!).

function factorial(n) {
if (n === 0) return 1;
return n * factorial(n - 1);
}

Объяснение: Рекурсивный спуск до базового случая (0! = 1). Альтернатива — цикл. Сложность O(n).

Задача 3: Проверка четности условие

Определить, является ли число N чётным.

if (n % 2 === 0) {
console.log("Чётное");
} else {
console.log("Нечётное");
}

Объяснение: Оператор % возвращает остаток от деления. Если остаток 0 — число чётное.

Задача 4: Максимум из трёх ветвление

Найти наибольшее из трёх чисел a, b, c.

let max = a;
if (b > max) max = b;
if (c > max) max = c;
console.log(max);

Объяснение: Последовательно сравниваем текущий максимум с каждым числом. Просто и эффективно.

Задача 5: Реверс строки строки

Перевернуть строку задом наперёд.

function reverse(str) {
let result = '';
for (let i = str.length - 1; i >= 0; i--) {
result += str[i];
}
return result;
}

Объяснение: Идём по строке с конца, добавляя символы в новую строку. Сложность O(n).

Задача 6: Линейный поиск массивы

Найти индекс элемента X в массиве (или -1).

function findIndex(arr, x) {
for (let i = 0; i < arr.length; i++) {
if (arr[i] === x) return i;
}
return -1;
}

Объяснение: Перебираем элементы по порядку. В худшем случае O(n).

Как работать с задачами

  • * Разбери условие, определи входные и выходные данные.
  • * Продумай алгоритм: какие переменные нужны, сколько шагов.
  • * Запиши псевдокод или код на знакомом языке.
  • * Проверь на крайних случаях (0, отрицательные, пустые массивы).
  • * Оцени сложность (O-нотацию).
